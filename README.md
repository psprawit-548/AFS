# Aftersale Service (AFS) — เวอร์ชัน Supabase (เรียลไทม์)

แอปจัดการเคสบริการหลังการขาย หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลอยู่บน Supabase
ทุกคนจึงเห็นข้อมูลชุดเดียวกัน และข้อมูลอัปเดตทันทีโดยไม่ต้องรีเฟรช

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอป (อัปขึ้น GitHub) |
| `supabase-setup.sql` | สร้างตาราง สิทธิ์ เรียลไทม์ และที่เก็บรูป (รันใน Supabase ครั้งเดียว) |

---

## ✅ ขั้นที่ 1–2 — ตั้งค่า Supabase (Claude ทำให้แล้ว)

- โปรเจกต์: **afs** (Region สิงคโปร์) แยกจากโปรเจกต์อื่นทั้งหมด
- Dashboard: https://supabase.com/dashboard/project/iyfbmbdsgfhfimvhfrvn
- สร้างตาราง ตั้งสิทธิ์ (RLS) เปิดเรียลไทม์ และสร้างที่เก็บรูปแล้ว
- ใส่ URL และ publishable key ลงใน `index.html` แล้ว

### ⚠️ สิ่งเดียวที่ต้องทำเองใน Supabase: ปิด "Confirm email"
เปิด https://supabase.com/dashboard/project/iyfbmbdsgfhfimvhfrvn/auth/providers
→ คลิก **Email** → ปิดสวิตช์ **Confirm email** → กด **Save**

ถ้าไม่ปิด ทีมจะต้องยืนยันอีเมลก่อนเข้าใช้ แต่ลิงก์ยืนยันจะยังพาไปผิดที่ และบริการส่งอีเมลฟรีของ Supabase ส่งได้แค่ไม่กี่ฉบับต่อชั่วโมง
การปิดไม่ทำให้ระบบหละหลวม เพราะ Admin ยังต้องอนุมัติผู้ใช้ทุกคนอยู่ดี

## ขั้นที่ 3 — เอาขึ้น GitHub Pages

1. ที่ https://github.com กด **+ → New repository** ตั้งชื่อ `afs` เลือก **Public** แล้วกด Create
2. กด **uploading an existing file** แล้วลาก `index.html` มาวาง จากนั้นกด **Commit changes**
   (ไม่ต้องอัป `supabase-setup.sql` ขึ้นไป แต่ถ้าอัปไปก็ไม่เป็นไร)
3. ไปที่ **Settings → Pages** เลือก Branch: **main** และ **/ (root)** แล้วกด **Save**
4. รอ 1–2 นาทีจะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/afs/`

## ขั้นที่ 4 — เริ่มใช้งาน

1. **คุณสมัครเป็นคนแรก** ที่แท็บ "สมัครใช้งาน" คนแรกของระบบจะได้สิทธิ์ **Admin** อัตโนมัติ
2. ส่งลิงก์ให้ทีมสมัคร คนที่สมัครหลังจากนั้นจะอยู่ในสถานะ **รออนุมัติ** และยังมองไม่เห็นข้อมูลใด ๆ
3. Admin ไปที่ **ผู้ใช้และสิทธิ์** แล้วเลือกบทบาทให้แต่ละคน: Manager, CS หรือช่าง
4. เพิ่มลูกค้าด้วย **อัปโหลด Customer Data** (.xlsx / .csv) หรือปุ่ม **+ เพิ่มลูกค้า**
5. ถ้าเคยใช้เวอร์ชันเก่าที่เก็บข้อมูลในเบราว์เซอร์ ให้เปิดแอปเวอร์ชันใหม่ในเครื่องเดิม
   แล้วไปที่ **ผู้ใช้และสิทธิ์ → ย้ายข้อมูลจากเบราว์เซอร์เครื่องนี้ขึ้น Supabase**
   (ปุ่มนี้จะแสดงเฉพาะเมื่อลิงก์ของแอปเป็นลิงก์เดียวกับที่ใช้เวอร์ชันเก่า)

## รูปแบบ Customer Data

แถวแรกต้องเป็นหัวคอลัมน์: `ชื่อลูกค้า | โครงการ | บ้านเลขที่ | ที่อยู่ | โทรศัพท์ | วันส่งมอบ`

- ต้องมีคอลัมน์ "ชื่อลูกค้า" ส่วนคอลัมน์อื่นจะใส่หรือไม่ก็ได้
- วันที่ใส่ได้ทั้งแบบ 15/03/2569 และ 2026-03-15

## ข้อควรรู้

- **แพ็กเกจฟรีของ Supabase** จะหยุดโปรเจกต์ชั่วคราวถ้าไม่มีใครใช้งานประมาณ 7 วัน ถ้าเจอ ให้เข้า Dashboard แล้วกด **Restore project** ข้อมูลไม่หาย
  ถ้าทีมใช้แอปทุกวันจะไม่เจอปัญหานี้
- **รูปภาพ** ถูกย่อให้อัตโนมัติ (ประมาณ 100–300 KB ต่อรูป) และเก็บใน Storage แบบ private ต้องล็อกอินจึงจะเห็นรูป
- **ลืมรหัสผ่าน:** Admin เข้าไปที่ Supabase → Authentication → Users → เลือกผู้ใช้ → Send password recovery
- **สำรองข้อมูล:** กด **ผู้ใช้และสิทธิ์ → สำรองข้อมูล (.json)** ได้ตลอด
- **อัปเดตแอป:** อัป `index.html` ตัวใหม่ทับใน GitHub ข้อมูลจะไม่หาย เพราะข้อมูลอยู่บน Supabase ไม่ได้อยู่ในไฟล์
